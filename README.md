# Booking Like

A polished, trustworthy online booking platform with a dramatic noir aesthetic.

## Overview

Booking Like is a professional booking website designed to convert visitors into customers through a clean, modern interface with high contrast and cinematic styling.

## Features

- **Service Catalogue**: Clear service descriptions with transparent pricing
- **Online Booking**: Streamlined booking form with date/time selection
- **Customer Accounts**: (Demonstration of) secure booking management
- **Email Reminders**: (Designed for) automated confirmation and reminder system
- **Responsive Design**: Mobile-first, accessible across all devices
- **Noir Aesthetic**: High-contrast design with dramatic gradients and sharp typography

## Pages

1. **Home** (`index.html`): Hero section, feature highlights, social proof, call-to-action
2. **Services** (`services.html`): Complete service catalogue with pricing and durations
3. **Book Now** (`book-now.html`): Booking form with calendar and time selection

## Design System

- **Primary Color**: #e5e5e5 (light gray)
- **Secondary Color**: #8a8a8a (medium gray)
- **Accent Color**: #c8102e (crimson red)
- **Background**: #0a0a0a (near black)
- **Foreground**: #f2f2f2 (off-white)
- **Typography**: Bebas Neue (headings), Source Sans 3 (body)
- **Style**: Sharp corners, flat cards, gradient backgrounds, moderate animation

## Technical Notes

- Pure HTML/CSS/JavaScript (no frameworks or external dependencies)
- All visuals created with inline SVG and CSS gradients
- WCAG AA compliant color contrast
- Forms are demonstration only and require backend integration for production use
- Scroll reveal animations for enhanced user experience

## Browser Support

Modern browsers (Chrome, Firefox, Safari, Edge) with CSS Grid and custom properties support.
